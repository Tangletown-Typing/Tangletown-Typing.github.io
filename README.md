# Tangletown-Typing.github.io

The website for Tangletown Typing™: the home page, privacy policy and support page for the store
listings. Plain static HTML served by GitHub Pages at https://tangletown-typing.github.io/; no build step.

- `index.html`: marketing page
- `privacy.html`: privacy policy (the stores' "Privacy Policy URL")
- `support.html`: support, FAQ, terms and credits (App Store "Support URL")
- `img/`: screens rendered by the app repo's `flutter test test_gallery/ --update-goldens`, plus the
  placeholder keycap mark (`mark.svg`) until the game has an app icon
- `fonts/`: Fredoka (SIL Open Font License), self-hosted so the site loads nothing from third parties
